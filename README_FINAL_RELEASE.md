## Chạy nhanh

Backend:

```bash
cd server
npm install
npm run dev
```

Frontend:

```bash
cd client
npm install
npm run dev
```

Mở trình duyệt tại URL Vite hiện ra trong terminal.

## Test theo thứ tự

## Ghi chú quan trọng

- ZIP không chứa `node_modules`.
- ZIP không chứa `server/.env`.
- ZIP không chứa API key.
- Nếu dùng Gemini thật, tạo lại file `server/.env` từ `server/.env.example`.
- Nếu chỉ demo offline, đặt `AI_PROVIDER=mock`.
